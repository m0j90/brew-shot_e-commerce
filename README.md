# ☕ Brew Shot E-Commerce

Welcome to the **Brew Shot E-Commerce** web application. This is a dynamic, responsive online shopping platform built using PHP for backend processing and Bootstrap 5 for modern styling.

## 🚀 Features
* **Interactive Shopping Cart:** Automatically updates and opens using custom JavaScript (`cart-auto-open.js`).
* **Secure Authentication:** User login and registration systems (`login-form.php`, `register.php`).
* **Admin Dashboard:** Management system located in the `/admin` folder to control products and orders.
* **Responsive Design:** Completely optimized for mobile and desktop views using Bootstrap 5.

## 🛠️ Built With
* **Backend:** PHP
* **Frontend:** JavaScript (ES6+), CSS3, Bootstrap 5
* **Data Storage:** JSON & MySQL Data Configurations

## 💻 Local Setup Instructions
To run this project on your Mac locally (using XAMPP, MAMP, or Laragon):

1. Clone or download this repository into your local server directory (e.g., `htdocs`).
2. Import the database configuration files located inside the `/data` folder into your local phpMyAdmin database.
3. Open your browser and navigate to: `http://localhost/brew-shot_e-commerce`
